The Regex Pattern

/^http:\/\/(?:localhost|\d{1,3}(\.\d{1,3}){3}):\d+\/?#?\//.test(window.location.href)

Test Cases

What This Pattern Tests:

  • Protocol: Must be HTTP (not HTTPS)
  • Host: Must be either "localhost" or an IP address (XXX.XXX.XXX.XXX)
  • Port: Must have a port number (e.g., :8080, :3000)
  • Path: Must end with /#/ or // or /

Common use case: Detecting if a web app is running in local development mode.
